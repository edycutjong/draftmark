Certify · code only

Code prints every number. Then it signs them.

Every station is signed (HMAC-SHA256). Edit one: REFUSE UNSIGNED. Past the table: REFUSE OUT_OF_TABLE.

No model writes a figure on the certificate. The refusal is the design: the program will not extrapolate past the hydrostatic table.
